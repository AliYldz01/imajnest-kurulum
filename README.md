## Bu sürümde

Çizim penceresi yenilendi
- Üst araç çubuğu 6 sekmeli şerit + hızlı erişim satırı; tüm düğmeler simgeli. Sağ panel: İlişki ekle, Hizala / yerleştir ve Düzenle grupları simgeli kutucuklar.
- Hizalama bağlı konturları (kare, dikdörtgen) ve grupları bütün olarak taşır; şekil bozulmaz.
- Ölçü değiştirince yatay / dikey ilişkiler korunur; etikete yakın uç hareket eder, uzak köşe yerinde kalır.
- Yatay / dikeye yakın çizilen her çizgiye otomatik ilişki; F8 orto kilidi; çizgi çizerken T teğet yay, L çizgi, C zinciri kapat; Enter son aracı tekrarlar.
- Kopyala / yapıştır / çoğalt / aynala / desen ilişkileri ve ölçüleri de taşır.
- Köşe yuvarlatma / pah: çerçeveyle çoklu köşe seçimi, hayalet önizleme, sağ panelde değer + Uygula (Enter).
- Ölçü etiketleri çakışmadan kaçınır; Yeniden yerleştir; ölçü görünümü (hepsi / seçili / sürücü / gizli, uzaktan sadeleştir); kalabalık ilişki işaretleri +N rozetine toplanır.
- Seçimden sonra imleç yanında hızlı menü (ilişkiler + ölçü ekle).
- Çelişki açıklaması penceresi (durum yazısına tıklayın), serbest nokta vurgusu, ilişki üzerinde gezince bağlı varlık vurgusu, benzerini seç, seçim filtresi, ötele / çoğalt pencerelerinde canlı önizleme, rakamla girilen değeri ölçü olarak ekleme seçeneği, DXF ekleme sonrası otomatik ilişki sorusu.
- Kullanım kılavuzu çizim bölümü yeni görüntülerle güncellendi.
